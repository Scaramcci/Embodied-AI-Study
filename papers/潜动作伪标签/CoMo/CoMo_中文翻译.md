## 摘要

从互联网视频中无监督学习潜在运动，对机器人学习至关重要。现有离散方法通常通过使用较小的向量量化码本，减轻模型从大量静态背景中进行捷径学习的问题。然而，这些方法会损失信息，难以捕捉复杂而细粒度的动态变化。此外，离散潜在运动的分布与连续机器人动作之间存在固有差距，妨碍了统一策略的联合学习。

我们提出 CoMo，目标是从互联网规模的视频中学习更加精确的连续潜在运动。CoMo 引入早期时间差分（Temporal Difference，Td）机制，提高捷径学习的难度并显式增强运动线索。为了让潜在运动更好地关注有意义的前景，我们进一步提出时间对比学习（Temporal Contrastive Learning，Tcl）：将未来帧时间偏移很小的样本构成正样本对，将时间方向反转的样本构成负样本。Td 与 Tcl 协同工作，使连续潜在运动更关注前景并强化与动作相关的运动线索。

CoMo 具有很强的零样本泛化能力，能够为未见过的视频生成有效的伪动作标签。大量仿真和真实世界实验表明，使用 CoMo 伪动作标签联合训练的策略，无论采用扩散式还是自回归式架构，都能取得更好的性能。代码将发布于：<https://github.com/MCG-NJU/CoMo>。

## 1. 引言

大规模互联网数据使视觉和语言模型获得了令人印象深刻的泛化能力，但机器人学习仍受到数据稀缺、数据多样性不足和数据异质性高的限制。为了有效扩展机器人学习，近期一种流行范式是从大量视频中学习潜在运动模型。这些方法通常采用“逆动力学编码器—前向动力学解码器”（IDM–FDM）结构，在视频帧对上进行自监督重建，同时加入 VQ-VAE 目标，对学习到的运动表示进行量化，从而为无标签视频生成伪动作标签。

先前方法倾向于使用离散潜在运动和小码本（例如 LAPA 使用 8 个码，UniVLA 使用 16 个码），主要原因是要抑制模型崩溃。若直接学习潜在运动，模型容易进行“捷径学习”：逆动力学编码器可能从未来帧中提取大量静态背景信息，而不是严格关注前景运动，因为这样可以更容易地重建像素级细节。这会使模型退化成无效的未来帧预测器，严重削弱其作为动作预测机制、用于联合训练统一机器人策略的价值。因此，使用小码本高度量化的潜在运动，只抽象时间范围内运动的大致方向或宏观趋势，以缓解这一问题。

然而，现实世界的运动本质上是连续的，包含复杂而细粒度的动态。用离散码本表示运动必然造成信息损失，并限制对新运动模式的泛化。视觉生成和机器人学习领域的证据也表明，连续表示可以带来更好的性能。这引出一个问题：能否从没有动作标签的视频中学习连续潜在运动？连续潜在运动能够更准确地表示帧间的细微变化，并且与机器人动作的连续性天然一致，有利于联合训练统一策略。

为解决直接学习连续潜在运动时的捷径学习问题，CoMo 首先引入早期时间差分策略。具体来说，模型不再直接编码未来帧，而是在输入编码器之前，计算当前帧和未来帧特征之间的差异。该操作增强了动态运动线索，同时提高捷径学习的难度。稀疏的特征差分显式放大运动信号，但在运动维度较大时也不可避免地包含无关信息。对此，CoMo 加入时间对比学习：未来帧具有轻微时间偏移的运动表示构成正样本对，而当前帧与未来帧的时间方向反转后得到的表示构成负样本对；随后使用 InfoNCE 损失学习更有结构的表示。

单独使用时间对比学习，可能只捕捉未来帧中前景物体的身份（“是什么”和“在哪里”），而忽略时间运动模式（“如何运动”）。因此，早期时间差分和时间对比学习必须协同工作，使 CoMo 学到的连续运动表示既关注有意义的前景区域，又包含与动作相关的运动线索。这样，CoMo 就能为无动作视频生成更准确的伪动作标签。

潜在运动学习还有一个额外难题：缺少直接、低成本且可靠的定量分析工具。本文采用两个指标：(1) 动作预测均方误差（MSE）；给定机器人数据集，训练一个 MLP 从潜在运动嵌入回归真实动作并报告 MSE，用来衡量潜在运动编码动作相关信息的能力。(2) 过去到当前、未来到当前相似度（S-PCFC）；在背景变化最小、以运动为中心的机器人示范数据上，计算从过去帧到当前帧和从未来帧到当前帧的运动表示之间的余弦相似度。高维潜在运动难免包含未来帧背景等与动作无关的冗余噪声，S-PCFC 用来诊断和量化这种噪声。实验发现，MSE 和 S-PCFC 同时较低时，通常对应最高的策略成功率。

总体而言，CoMo 可以为无动作视频生成有效的伪动作标签。视频潜在运动与机器人动作具有一致的连续分布，可以直接促进统一策略的联合学习，免去复杂的多阶段预训练和微调流程，也不需要显式的“先运动、后动作”两阶段管线。仿真和真实世界实验验证了 CoMo 相对于离散潜在运动和朴素连续基线的优势。

本文贡献如下：

1. 提出 CoMo，从互联网视频中无监督学习细粒度、信息丰富且连续的潜在运动表示。
2. 去除向量量化，提出早期时间差分和时间对比学习，使连续潜在运动更聚焦于有意义的前景并增强动作相关线索。
3. 使用 CoMo 为无动作视频生成更精确的伪动作标签。潜在运动和机器人动作的连续分布一致性，天然支持统一策略的联合学习。
4. 在扩散式和自回归式策略上进行大量仿真与真实世界实验，证明 CoMo 的优越性能。

## 2. 相关工作

### 2.1 从互联网数据学习机器人操作

机器人数据有限，限制了可扩展的策略学习。引入大规模互联网视频可以提高泛化能力和数据效率。现有方法从视频中预测各种信号：有些把它们作为改善策略学习的隐式辅助任务，有些把它们作为执行策略时的显式引导。这些信号包括未来视觉观测、可供性、物体掩码、光流、人手姿态和稀疏点轨迹。近期流行的框架使用 IDM–FDM 结构和无监督 VQ-VAE 目标，从无动作视频中提取离散潜在运动，通常是为了对抗捷径学习。另一些工作加入机器人动作监督来训练连续潜在运动 IDM，或学习带潜动作的连续世界模型。CoMo 专注于完全自监督的连续潜在运动 IDM，避免 VQ-VAE 方法中的表示权衡。

### 2.2 机器人操作策略架构

早期工作主要使用基于状态的强化学习；近期方法则利用原始视觉观测进行模仿学习。许多方法使用生成式概率模型来捕捉复杂的多模态动作分布。一类方法采用自回归策略架构，受益于预训练视觉语言模型的泛化能力，但需要将机器人动作离散化；另一类方法使用基于扩散的策略架构，直接生成连续机器人动作。近期研究表明，连续动作表示可以实现更细致的行为建模并带来更好的性能。因此，很多先进方法将自回归视觉语言模型骨干与扩散动作专家结合，同时获得预训练模型的泛化能力和连续动作表示的表达能力。CoMo 可以在此基础上使用统一策略架构，联合学习连续机器人动作和视频潜在运动。

## 3. 方法

### 3.1 学习连续潜在运动

CoMo 采用逆动力学编码器—前向动力学解码器范式，如图 1 所示。

**图 1（位置标注）：CoMo 框架。** 左图为 CoMo 模型结构：当前帧和未来帧经过共享的 MAE 预训练 ViT，计算特征差分，再由运动查询模块得到连续潜在运动；前向动力学模型使用该运动和当前观测预测未来帧。右图为时间对比学习：轻微时间偏移的运动表示为正对，时间方向反转的表示为负对。该框架在标准 IDM–FDM 结构上学习无 VQ、连续且更精确的帧间潜在运动。

#### 带早期时间差分的逆动力学模型

给定当前帧 $O_t$ 和未来帧 $O_{t+n}$，使用共享的 MAE 预训练 ViT 提取各自的 token 级特征 $F_t$ 和 $F_{t+n}$。随后，为增强动作相关的运动线索，对两组特征逐元素相减，得到 token 级时间特征差分 $D_t$。为了进一步抑制静态背景和捷径学习，在提取运动嵌入之前显式移除未来帧特征。也就是说，编码器只接收当前帧特征和时间差分：

$$[F_t,D_t].$$

参考 Moto-GPT，把一组可学习的查询嵌入与 token 级组合表示拼接，并在标准多层 Transformer（Motion Q-Former）中进行全注意力交互。取 Transformer 输出中的查询特征作为运动表示 $Z_{t,t+n}$。

#### 通过时间对比学习学习潜在运动

在不使用向量量化的情况下学习连续潜在运动，核心挑战是模型可能提取过多静态未来帧背景。早期时间差分通过移除未来帧特征来增强运动线索并提高捷径学习难度，但仅靠稀疏特征差分仍可能包含大量无关信息。为此，CoMo 进一步进行时间对比学习。

从 $O_{t+n}$ 附近采样 $O_{t+n+\delta}$，并使用 IDM 得到 $Z_{t,t+n+\delta}$、$Z_{t+n,t}$。定义：

$$S_1=S(Z_{t,t+n+\delta},Z_{t,t+n}),$$
$$S_2=S(Z_{t,t+n+\delta},Z_{t+n,t}),$$
$$S_3=S(Z_{t,t+n},Z_{t+n,t}),$$
$$L_{tcl}=-\log\frac{e^{S_1}}{e^{S_1}+e^{S_2}+e^{S_3}}.$$

其中 $S$ 是余弦相似度。时间轻微偏移的 $(Z_{t,t+n+\delta},Z_{t,t+n})$ 是正运动对；$(Z_{t,t+n+\delta},Z_{t+n,t})$ 和 $(Z_{t,t+n},Z_{t+n,t})$ 是时间方向相反的负运动对。实践中将 $\delta$ 的范围设为 $[-n/5,n/5]$。

单独使用 Tcl 可能只捕捉未来帧前景物体的身份，而忽略时间运动模式；因此 Td 与 Tcl 协同缓解捷径学习。两者共同使连续潜在运动聚焦有意义的前景并增强动作相关线索。由于不需要严格的向量量化约束（如小码本或低维运动嵌入），CoMo 的运动维度更容易扩展。

#### 前向动力学模型

前向动力学解码器以 IDM 得到的潜在运动 $Z_{t,t+n}$ 和当前视觉观测 $O_t$ 为条件，重建未来观测 $O_{t+n}$。首先通过线性 patch 嵌入层得到 $O_t$ 的低层 patch 嵌入；同时对运动表示 $Z_t$ 做池化压缩，并将池化后的运动特征加到 $O_t$ 的低层 patch 嵌入上，得到 $E(O_t,Z_{t,t+n})$。多层 Transformer 处理组合特征，最后通过卷积层和像素重排操作重建预测帧 $\hat O_{t+n}$。

CoMo 联合最小化加权 InfoNCE 损失、重建损失和感知损失，确保预测帧同时具备像素级准确性和感知层面的真实感。

### 3.2 统一策略的联合学习

设带动作标签的机器人数据集为 $D_R=\{\tau_1,\ldots,\tau_n\}$，每条轨迹由观测和动作对组成：

$$\tau_i=[(o_0,a_0),\ldots,(o_T,a_T)]。$$

另有规模更大的无动作视频数据 $D_V$。使用训练好的 CoMo IDM 从 $D_V$ 提取连续潜在运动嵌入后，每条视频轨迹可以扩展为：

$$[(o_0,z_0),\ldots,(o_T,z_T)]，$$

其中 $z_t$ 是 IDM 在时间步 $t$ 推断的潜在运动。由于 $a$ 和 $z$ 都服从连续数据分布，可以直接在组合数据集 $D_R\cup D_V$ 上使用统一生成式策略进行联合模仿学习，只需为机器人动作和视频潜在运动分配不同的轻量级输出头。这种联合训练不需要复杂的多阶段预训练、微调流程，也不需要显式的两阶段“运动先于动作”管线。利用更大规模的数据源，CoMo 提供了一种可扩展的机器人学习范式。本文实现了统一的扩散式策略和自回归式策略。

## 4. 实验

实验使用 LIBERO 和 CALVIN 基准，以及 Franka Emika Research 3 机器人，研究以下问题：

- **Q1：** 自监督 CoMo 能否从无动作视频中提取有效的伪动作标签，并与机器人数据统一联合训练以提升策略性能？
- **Q2：** 早期时间差分（Td）和时间对比学习（Tcl）分别有什么作用，能否协同改善潜在运动表示？
- **Q3：** CoMo 的连续潜在运动能否缓解捷径学习，并超过离散潜在运动、朴素连续基线及其他相关方法？
- **Q4：** CoMo 提取的连续潜在运动维度能否方便地扩展？
- **Q5：** MSE 和 S-PCFC 能否有效评估、分析潜在运动表示，并可靠反映下游策略成功率？
- **Q6：** 在双臂和人形机器人等更复杂、采用绝对动作空间的具身形态上，CoMo 是否仍然有效并具备泛化能力？

### 4.1 使用域外互联网视频学习潜在运动

为评估潜在运动编码器的零样本跨域迁移能力，本文不使用同域机器人数据训练编码器，而是在大规模域外互联网视频上联合训练。分别从 SAM-V、EgoVid 和 Droid 均匀采样 40,000 个视频，共 120,000 个。三类数据覆盖野外视频、第一视角人类视频和机器人视频。所有后续实验都使用这一固定数据集，保证不同方法的比较公平且一致。

### 4.2 仿真实验

#### 4.2.1 基准与设置

**LIBERO。** LIBERO 包含 Spatial、Object、Goal、Long 和 LIBERO-90 五个类别。为进行统一策略联合训练，每个任务只使用 10 条机器人轨迹，剩余轨迹是通过潜在运动 IDM 标注伪动作的视频轨迹。策略采用基于扩散的架构，对机器人动作和潜在运动进行联合去噪。在真实机器人动作空间和潜在运动空间中分别计算成功率。每个任务评估 20 次，重复三次并报告均值和标准差。

**CALVIN。** CALVIN 基于 Franka 机器人，用于评估长时程任务完成能力，包含 A、B、C、D 四个环境。实验采用最具挑战性的 ABC→D 设置：在 A、B、C 上训练，在 D 上评估。与 Moto-GPT 不同，本文使用完全域外的视频训练潜在运动 IDM，并使用 A、B、C 数据中的 35%（约 18,000 条带语言标注的轨迹视频）进行统一策略联合训练。为在统一自回归策略中同时预测连续机器人动作和潜在运动，在自回归解码器的最终隐藏状态后加入两个 MLP 网络。

#### 4.2.2 MSE 与 S-PCFC

成功率容易受到外部因素影响、评估成本较高，而且不能直接衡量潜在运动属性。因此，本文使用两个直接、稳定且低成本的指标。

**动作预测均方误差（MSE）。** 按照常用的运动表示评估协议，使用离线提取的运动嵌入 $z_t$ 训练 MLP 回归真实机器人动作 $a_t$，并报告 MSE。MSE 衡量潜在运动编码动作相关信息的能力。

**过去到当前、未来到当前相似度（S-PCFC）。** 为直接测量动作无关的背景噪声，并公平比较不同维度的潜在运动，定义：

$$\mathrm{S\mbox{-}PCFC}(t)=\frac{z(o_{t-n},o_t)^\top z(o_{t+n},o_t)}{\|z(o_{t-n},o_t)\|_2\,\|z(o_{t+n},o_t)\|_2}.$$

其中 $n$ 是较小的时间步偏移。S-PCFC 在运动中心的机器人数据上统计，这些数据具有受控环境、较小的背景变化、明显运动和周期性运动，因此指标主要对运动动力学敏感，而不是对视频噪声敏感。高维潜在运动必然包含冗余噪声，所以较低的 S-PCFC 表示更好的运动保真度和更少的静态冗余。

朴素连续基线容易把提示视频中的静态背景噪声带入潜在运动，并传播到新环境的未来帧预测。Td 可以有效抑制该问题，但只使用 Td 得到的潜在运动可能较稀疏；加入 Tcl 后，运动更聚焦前景、更有结构，帧间变化和未来帧预测也更准确。随着潜在运动维度增加，仅使用 Td 会使 S-PCFC 上升，说明表示中积累了动作无关噪声；CoMo 则保持较低的 S-PCFC，同时 MSE 继续下降，因此维度更容易扩展。

## 5. 真实世界实验

### 5.1 设置

真实实验使用一台 Franka 机器人执行五项任务：抓取玩具放入篮子、打开抽屉、关闭抽屉、将面包插入容器、将球倒入篮子（见图 4）。每个任务采集 25 条遥操作轨迹和 25 段同一环境中的人手操作视频，再使用潜在运动 IDM 为人手视频构造伪动作标签。使用两类数据训练统一的扩散策略，每项任务进行 20 次测试。

机器人系统配备 UMI 夹爪和固定位置的 RealSense D435 相机，从第三人称视角获取 640×480 的 RGB 观测；使用 3D 鼠标进行遥操作。控制频率为 20 Hz，动作定义为 SE(3) 空间中的末端执行器相对位姿变化（3D 位置变化、四元数方向变化和夹爪状态）。抽屉任务在底部粘贴材料，减小打开和关闭过程中的明显滑动；抽屉初始位置在横向和纵向约 8 cm 范围内扰动。

**图 4（位置标注）：真实任务示意图。** 从左到右为打开抽屉、倒球、抓取并放置茄子、插入面包、关闭抽屉。

**图 5（位置标注）：真实世界实验的 Franka 机械臂硬件平台。** 图中展示机械臂、UMI 夹爪、固定的第三人称相机及桌面操作区域；实验通过该平台采集机器人示范，并在相同环境中录制人手操作视频。

CoMo 从人类示范视频中提取伪动作标签的效果最好，真实策略性能也优于朴素离散和连续基线。这可能来自三方面：连续分布与真实机器人动作匹配、能够更精确地捕捉潜在运动、减少动作无关的背景噪声。优势在打开抽屉、插入面包等容错范围小、需要细致操作的任务中尤其明显。

## 6. 结论

本文提出 CoMo，一种从互联网视频中自监督学习连续潜在运动的框架。通过早期时间差分和时间对比学习，CoMo 有效缓解捷径学习，使无动作视频能够产生更有效、更精确的伪动作标签，并在统一策略中无缝联合学习连续机器人动作和潜在运动。本文还提出 MSE 和 S-PCFC，用于更直接、稳定地评估和分析潜在运动，实验显示 CoMo 学到的运动具有更好的属性。仿真和真实世界实验验证了 CoMo 相对于离散潜在运动和朴素连续基线的优势。

## 7. 局限性与讨论

尽管 CoMo 在提取无动作视频伪标签方面有效且泛化性强，MSE 和 S-PCFC 也显著优于基线，但策略联合训练在某些任务上的收益仍然有限。这可能是因为 CoMo 的优势主要体现在细粒度任务上。因此，构建规模更大、更加复杂、专门评估真实细粒度操作的基准十分重要。未来还可以将 CoMo 扩展到多帧和多视角建模，以减轻遮挡并进一步提高运动提取精度。

### A.4 自回归策略

自回归策略主要用于 CALVIN。使用 T5 和 ViT 提取文本和视觉 token 特征，采用 GPT 风格的自回归骨干，并在输出层加入两个 MLP，分别预测连续机器人动作和潜在运动，损失均为 MSE。潜在运动以块大小 2 自回归预测；动作使用可学习动作查询 token 并行解码，块大小为 5。为公平比较离散基线，先在无动作视频上预训练一轮潜在运动预测，再与机器人动作和无动作视频联合训练。
