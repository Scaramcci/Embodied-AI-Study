# 互联网 2D 视频用于机器人学习、数据合成与深度恢复：论文清单

检索日期：2026-09-17。根据 VidBot、Qwen-RobotManip、Ego2Robot 的阅读方向筛选。来源以作者论文、作者项目页、官方研究机构页面和官方代码仓库为主。

这份清单关心的是：大量普通 RGB 视频没有机器人动作标签，怎样通过自动处理变成机器人可以学习的监督？路线包括显式三维重建、隐式动作学习、视频数据编辑、未来状态学习和视频生成。

“生成深度图”“恢复三维手部轨迹”“生成机器人可执行动作”是三种不同输出。论文有三维动作，不代表它发布了逐帧深度数据；用到互联网视频，也不代表部署完全不需要机器人示范或 RGB-D 相机。以下规模来自各论文/项目页，小时、片段和帧不是可直接比较的单位。不同论文的性能数字也不宜跨评测直接排名。

## 建议优先阅读

如果主要看大规模人类视频预训练：**VITRA → Being-H0 → JALA → Being-H0.5 / Being-H0.7 → LDA-1B**。

如果主要看 RGB 视频转机器人数据：**Masquerade → Do as I Do**，与已有 Ego2Robot 对照。

如果主要看无动作标签的视频怎么训练：**LAPA → CoMo → villa-X**。

如果主要看生成带深度的视频：**Video Depth Anything → DepthCrafter → Depth Anything 3 → MoGe-2 / VGGT**，再看 Dream2Flow 如何把三维信息连接到控制。

上面的阅读排序是结合你的目标给出的判断，不是论文排行榜。

## 一、大规模人类视频与 VLA / 世界动作模型预训练

### 1. VITRA：最贴近“普通视频自动处理后，大规模训练机器人”

全名：*Scalable Vision-Language-Action Model Pretraining for Robotic Manipulation with Real-Life Human Activity Videos*，2025 预印本，ICRA 2026。

输入是非脚本化、无标注的第一人称人类活动视频。自动把长视频分成原子动作，生成语言描述，恢复逐帧三维手部运动和相机运动；把双手视作末端执行器，转换为与机器人 VLA 数据相容的格式。

作者项目页报告 **1M 段示范、26M 帧**。先在这些数据上预训练，再用少量真实机器人动作数据微调，并展示随预训练数据量增长的性能改善。

**与你的需求的关系：** 同时研究自动标注、三维轨迹恢复、数据规模和机器人迁移，比只用视频做视觉特征预训练更接近 VidBot / Ego2Robot。

**Depth：** 主要交付和训练接口是三维手部/相机运动，不能仅据此认定它发布了完整逐帧深度图数据集。

来源：[论文](https://arxiv.org/abs/2510.21571)、[作者项目页，含代码、模型、数据入口](https://microsoft.github.io/VITRA/)。

### 2. Being-H0：先用大规模人类视频学习物理交互

全名：*Being-H0: Vision-Language-Action Pretraining from Large-Scale Human Videos*，2025 预印本。

提出 physical instruction tuning，把人类视频 VLA 预训练、用于三维推理的物理空间对齐，以及机器人任务后训练连接起来。使用部件级运动 token 化表示手部轨迹。

**值得看什么：** 从人类运动知识到机器人动作的训练桥梁，以及怎样让 VLM 不只理解“这是什么”，还理解“物理空间里怎么动”。

**Depth：** 重点是物理空间和动作表示，不是独立的视频深度生成模型。

来源：[论文](https://arxiv.org/abs/2507.15597)、[作者官方代码仓库，覆盖 Being-H 系列](https://github.com/BeingBeyond/Being-H0)。

### 3. JALA：处理海量自然视频里“不可靠的手部动作标签”

全名：*Joint-Aligned Latent Action: Towards Scalable VLA Pretraining in the Wild*，2026。

这是特别适合与显式重建路线对照的一篇。自然环境视频多，但手部跟踪标签不稳；高精度标注数据则少。JALA 不依赖完整视觉动态重建，而学习同时与逆动力学和真实动作对齐的预测性动作嵌入。

使用 **UniHand-Mix：7.5M 视频、超过 2,000 小时**，混合实验室和自然环境来源，验证下游仿真及真实操作。

**值得看什么：** 大规模伪标签存在误差时，能否通过联合对齐学到更有行为意义的隐空间，而不是把全部重建误差当真实动作监督。

**Depth：** 不以生成深度图为目标，属于隐式动作表示。

来源：[论文](https://arxiv.org/abs/2602.21736)。

### 4. Being-H0.5：人类数据与多机器人数据大规模统一

全名：*Being-H0.5: Scaling Human-Centric Robot Learning for Cross-Embodiment Generalization*，2026。

把人类交互轨迹视为物理交互的通用基础表示，提出 Unified Action Space，把异构机器人控制映射到语义一致槽位。UniHand-2.0 预训练配方包含 **超过 35,000 小时多模态数据、30 种机器人形态**。

架构使用 Mixture-of-Transformers 和 Mixture-of-Flow，区分共享运动原语与机器人专用专家，并处理真实部署感知变化和不同控制延迟。

**注意规模口径：** 35,000 小时是混合多模态数据，不是全部来自无标注互联网 RGB 视频。

**与你已有论文的关系：** 与 Qwen-RobotManip 一样，核心问题是“异构数据如何统一后才能扩大规模”，适合对照动作表示和训练混合策略。

来源：[论文](https://arxiv.org/abs/2601.12993)、[系列官方仓库](https://github.com/BeingBeyond/Being-H0)。

### 5. Being-H0.7：视频的未来信息用于动作学习，推理不必生成视频

全名：*Being-H0.7: A Latent World-Action Model from Egocentric Videos*，2026。

在感知和动作之间加入可学习潜在查询。训练时，用能看到未来观察的 posterior 分支提供未来监督；部署 prior 分支只看当前上下文，两个分支在潜在推理空间对齐。

推理丢弃 posterior，不生成未来图像，不进行视频 rollout。

**值得看什么：** 能否利用大量视频里的接触、动态和任务进度信息，又避免像素空间视频生成的计算开销。

**Depth：** 不是深度生成，主要是未来感知的潜在世界动作表示。

来源：[论文](https://arxiv.org/abs/2605.00078)、[作者说明](https://research.beingbeyond.com/being-h07)。

### 6. LDA-1B：不同质量的视频、动作数据分别承担不同训练作用

全名：*LDA-1B: Scaling Latent Dynamics Action Model via Universal Embodied Data Ingestion*，2026。

统一学习动力学、策略和视觉预测，而不只做行为克隆。整理 EI-30k，包含 **超过 30,000 小时的人类和机器人轨迹**，按数据质量分配不同作用。

在结构化 DINO 潜在空间预测，减少不相关外观的建模；多模态扩散 Transformer 处理不同步的视觉和动作流。

**值得看什么：** 当可用数据有“高质量动作示范”“低质量轨迹”“没有动作的视频”时，如何让它们分别贡献，而不是直接混在同一个动作克隆目标里。

**Depth：** 核心接口是潜在视觉动态，不是逐帧深度图。

来源：[论文](https://arxiv.org/abs/2602.12215)。

## 二、不需要真实动作标签：从视频学习潜在动作

### 7. LAPA：这个方向的重要起点

全名：*Latent Action Pretraining from Videos*，2024 预印本，ICLR 2025。

先用 VQ-VAE 类目标，学习相邻图像之间的离散潜在动作；再让 VLM 根据当前图像和任务文本预测潜在动作；最后用小规模机器人动作数据，把潜在动作映射到可执行控制。

人类视频实验使用 **Something-Something V2 的 220K 视频**。预训练无需真实机器人动作标签，落地阶段仍有机器人动作微调。

**与你的需求的关系：** 提供绕开“每段互联网视频都必须准确恢复三维动作”的路线。它学习视觉变化中的动作抽象。

**Depth：** 不需要先产生显式深度标签；潜在动作也不是机器人关节命令。

来源：[论文](https://arxiv.org/abs/2410.11758)、[项目页](https://latentactionpretraining.github.io/)、[官方代码](https://github.com/LatentActionPretraining/LAPA)。

### 8. CoMo：从离散动作转向连续潜在运动

全名：*CoMo: Learning Continuous Latent Motion from Internet Videos for Scalable Robot Learning*，2025 预印本；存在 CVPR 2026 官方论文版本。

从互联网视频无监督学习连续运动表示，针对离散码本的信息损失和模型容易记静态外观的捷径。正式版本通过早期时间差分增强运动线索，结合时间对比学习，让潜在表示关注前景行为。

把学习到的表示用于未见视频的伪动作标注，再与机器人动作数据共同训练策略。潜在连续运动与连续机器人动作不是同一物理量，但更便于联合建模。

**值得看什么：** 数据量变大时，怎样确保模型学“怎么动”，而不是学“背景长什么样”。不同公开版本方法细节有变化，阅读时建议以选定版本为准。

来源：[arXiv](https://arxiv.org/abs/2505.17006)、[CVPR 2026 官方 PDF](https://openaccess.thecvf.com/content/CVPR2026/papers/Yang_CoMo_Learning_Continuous_Latent_Motion_from_Internet_Videos_for_Scalable_CVPR_2026_paper.pdf)、[官方代码](https://github.com/MCG-NJU/CoMo)。

### 9. villa-X：让潜在动作同时预测视觉变化和机器人状态变化

全名：*villa-X: Enhancing Latent Action Modeling in Vision-Language-Action Models*，2025 预印本。

潜在动作模型包含逆动力学、视觉前向动力学和本体前向动力学；动作模块同时预测潜在动作和机器人动作。使用机器人数据及 Something-Something V2、Ego4D 等人类视频。

**值得看什么：** 只重建下一帧可能让潜在动作与真实控制脱节，加入机器人状态与动作预测，怎样让潜在表示更适合执行。

**Depth：** 不是深度生成模型。

来源：[论文](https://arxiv.org/abs/2507.23682)、[作者项目页](https://microsoft.github.io/villa-x/)、[官方代码](https://github.com/microsoft/villa-x/)。

### 10. LAWM：通过世界建模预训练潜在动作

全名：*Latent Action Pretraining Through World Modeling*，2025。

用机器人或人类操作物体的视频，自监督学习潜在动作表示，强调能适配不同模仿学习模型，以及任务、环境和机器人形态迁移。

**值得看什么：** 作为 LAPA 之后的补充，关注世界建模与动作隐空间的连接，而非每帧三维重建。

来源：[论文](https://arxiv.org/abs/2509.18428)。

## 三、把人类 RGB 视频“机器人化”，或者恢复可执行的三维交互

### 11. Masquerade：最接近 Ego2Robot 的 RGB 数据编辑路线

全名：*Masquerade: Learning from In-the-wild Human Videos using Data-Editing*，2025 预印本，ICRA 2026。

输入 EPIC-KITCHENS RGB 视频；估计手部姿态，分割并修复双臂区域，再叠加跟随人手估计运动的双臂机器人。先训练编码器预测未来机器人关键点，再和少量真实机器人数据联合训练扩散策略。

作者说明使用一个场景的 **50 段真实机器人示范**。数据编辑后的 **二维投影路标是辅助监督，不是完整三维机器人动作真值**；没有真实深度导致沿深度方向约 3-4 cm 的误差。

**值得看什么：** 视觉机器人化本身是否有效，如何在三维动作不够可靠时仍利用人类视频。

来源：[作者项目页](https://masquerade-robot.github.io/)、[官方共享代码，清楚区分 Phantom 与 Masquerade](https://github.com/MarionLepert/phantom/blob/main/README.md)。

### 12. Do as I Do：从 RGB 视频到多指灵巧手数据

全名：*Do as I Do: Dexterous Manipulation Data from Everyday Human Videos*，2026-06。

输入第一人称或第三人称的单目 RGB 人类视频，重建手与物体交互，再重定向为多指机器人灵巧手在真实世界可执行的动作序列。验证包括有真值的数据和网上采集的视频片段。

**与你已有论文的区别：** Ego2Robot 的主要重定向对象是平行夹爪；这篇直接面对多指灵巧手及手物交互，更值得用于比较重定向和可执行性。

**Depth：** 有显式三维交互重建，但不能因此认定输出是完整逐帧场景深度数据集。它是数据生成方法，不应直接称为已验证的互联网巨量 VLA 预训练配方。

来源：[论文](https://arxiv.org/abs/2606.19333)、[作者项目页](https://do-as-i-do.com/)。

### 13. Track2Act：先预测二维点轨迹，再推导机器人动作

全名：*Track2Act: Predicting Point Tracks from Internet Videos enables Generalizable Robot Manipulation*，2024。

使用网上人类和机器人操作视频，学习给定目标时图像中的点将如何运动。将二维轨迹转换成物体刚体变换与末端位姿，再用少量机器人专用示范训练闭环残差策略。

**值得看什么：** 与 VidBot 的三维手轨迹不同，这里主要学物体/图像点运动，依靠几何推导把视觉计划接到控制。

**Depth：** 主学习标签是二维点轨迹；不能把二维视频训练与运行时无需三维感知画等号。

来源：[论文](https://arxiv.org/abs/2405.01527)、[作者项目页](https://homangab.github.io/track2act/)。

### 14. ATM：任何点的运动轨迹都可以作为机器人学习接口

全名：*Any-point Trajectory Modeling for Policy Learning*，2023 年底预印本，RSS 2024。

先从无动作标签的视频学习预测任意点未来轨迹，再用轨迹特征指导少量动作标注下的策略学习。展示人类视频和不同机器人形态视频的迁移。

**值得看什么：** “视频 → 点追踪 → 轨迹模型 → 策略”的完整训练接口，有利于理解为何无需每帧人工动作标签也能提供控制信息。

**Depth：** 不以生成场景深度为核心。

来源：[论文](https://arxiv.org/abs/2401.00025)、[作者项目页](https://xingyu-lin.github.io/atm)。

## 四、视频生成 / 世界模型为机器人提供训练信号

### 15. DreamGen：用生成视频扩大机器人训练数据

全名：*DreamGen: Unlocking Generalization in Robot Learning through Video World Models*，2025。

先适配视频世界模型到目标机器人，再输入初始图像和语言生成机器人执行视频，用潜在动作或逆动力学模型提取伪动作，最后把视频和伪动作用于机器人策略训练。

**值得看什么：** 从“扩大真实遥操作采集”转向“扩大 GPU 生成”，以及生成的新任务和新场景能否变成可用训练轨迹。

**数据来源区别：** 核心是预训练视频模型的知识及合成视频，不是把任意互联网人手视频直接转成精确动作。视频模型和动作提取器仍需要目标机器人适配数据。

来源：[NVIDIA 官方研究页](https://research.nvidia.com/labs/gear/dreamgen/)、[官方代码](https://github.com/NVIDIA/GR00T-Dreams)。

### 16. Dream2Flow：生成视频 + 深度 + 三维物体流 → 控制

全名：*Dream2Flow: Bridging Video Generation and Open-World Manipulation with 3D Object Flow*，2025 年底预印本。

根据初始图像和指令生成交互视频，用视觉基础模型获得物体掩码、视频深度和点追踪，重建三维物体流。随后通过轨迹优化或强化学习，让机器人跟踪物体变化，得到低层命令。

**这篇特别适合你的 Depth 兴趣：** 深度并非只用于美观展示，而是与点轨迹结合，把二维生成视频转为三维控制目标。可涵盖刚体、关节物体、可变形物体和颗粒。

**机器人训练需求：** 作者强调不需要任务专用示范，但执行接口仍有控制器/轨迹优化或强化学习，不等于没有任何机器人建模。

来源：[论文](https://arxiv.org/abs/2512.24766)、[作者项目页](https://dream2flow.github.io/)。

### 17. FLARE：人类无动作视频只参与未来特征对齐

全名：*FLARE: Robot Learning with Implicit World Modeling*，2025。

用未来视觉特征对齐训练策略。机器人示范同时提供动作流匹配和未来对齐；人类视频没有机器人动作，所以只提供未来对齐损失。

**值得看什么：** 同一个模型如何让有动作与无动作数据承担不同损失，不必先给每个人类视频制造精确动作伪标签。

**规模区别：** 官方人类视频实验是头戴 GoPro 收集的示范，不能把它描述成已经在全网巨量视频上验证。它对无动作视频联合训练的机制很有参考价值。

来源：[NVIDIA 官方研究页](https://research.nvidia.com/labs/gear/flare/)。

### 18. LUCID：互联网视频学意图，仿真学如何执行

全名：*LUCID: Learning Embodiment-Agnostic Intent Models from Unstructured Human Videos for Scalable Dexterous Robot Skill Acquisition*，2026-06。

从非结构化人类视频学习短时序意图，也就是场景下一步应该发生什么；通过大规模并行仿真训练机器人专用感知运动控制器，把共享意图变成动作。

验证五个真实任务：搅拌、擦拭、入桶由互联网视频提供监督；push-T 和线缆布线各使用一小时自录手机视频。

**值得看什么：** 不重建整套人手动作，而学习形态无关的任务变化，再由形态相关控制器完成，连接互联网数据与仿真扩展。

来源：[论文](https://arxiv.org/abs/2606.11628)、[作者项目页](https://lucid-robot.github.io/)。

### 19. AVDC：无动作视频的经典视频计划路线

全名：*Learning to Act from Actionless Videos through Dense Correspondences*，2023 预印本，ICLR 2024。

先生成任务执行视频，再从帧间稠密对应关系/光流推导物体运动与可执行动作，用 IK 和规划器完成控制，不要求训练视频具有显式动作标签。

**规模区别：** 重点是“没有动作标签也能控制”的方法，并非巨量互联网预训练代表；适合追溯 Dream2Flow 等视觉计划转控制路线。

来源：[论文](https://arxiv.org/abs/2310.08576)、[官方代码](https://github.com/flow-diffusion/AVDC)。

### 20. UniPi：语言指导视频计划，再通过逆动力学执行

全名：*Learning Universal Policies via Text-Guided Video Generation*，2023。

以文本表示目标，以视频表示不同环境的行为。视频生成器预测达到目标的视觉轨迹，逆动力学模型提取低层动作。研究组合语言、长时序任务和非机器人视频知识。

**值得看什么：** 世界模型并不一定直接输出动作，可以用视频作为共享计划接口；执行仍需动作映射。

来源：[Google Research 官方介绍](https://research.google/blog/unipi-learning-universal-policies-via-text-guided-video-generation/)。

## 五、普通 RGB 视频 / 图像生成深度与三维几何

以下是数据处理模块论文，不能直接当作完整机器人策略。它们可以为 VidBot、Ego2Robot 这类流程提供几何伪标签。

### 21. Depth Anything 与 Depth Anything V2：规模化伪标签深度

V1 全名：*Depth Anything: Unleashing the Power of Large-Scale Unlabeled Data*，2024。通过自动收集标注 **约 62M 未标注图像**，扩大覆盖、改善单目深度泛化。

V2（2024）使用高质量合成标签、更强教师，再通过大量伪标注真实图像训练学生。明确有通过米制深度标注微调的 metric 模型。

**与你的兴趣的关系：** 它们本身就是“靠大量便宜数据 + 自动伪标签扩展基础模型”的代表。

**关键区别：** 通用相对深度模型和米制深度模型不同；单图效果好，也不能保证直接逐帧处理视频没有闪烁或尺度漂移。

来源：[V1 论文](https://arxiv.org/abs/2401.10891)、[V2 论文](https://arxiv.org/abs/2406.09414)、[作者项目页](https://depth-anything.github.io/)。

### 22. Video Depth Anything：长 RGB 视频的时序一致深度

全名：*Video Depth Anything: Consistent Depth Estimation for Super-Long Videos*，2025，CVPR 2025。

基于 Depth Anything V2，加入高效时空头、时间深度梯度约束和关键帧长视频推理策略，输出长序列深度。训练混合视频深度与无标注图像。

**优先级很高：** 如果目标是给一批人类 RGB 视频补上逐帧深度，这是最直接的候选之一。

**需要核对：** 具体 checkpoint 的相对/米制深度、跨帧尺度一致性、输出精度，而不能把展示用灰度图当真实米制标签。

来源：[论文](https://arxiv.org/abs/2501.12375)、[作者项目页及代码入口](https://videodepthanything.github.io/)。

### 23. DepthCrafter：通过视频扩散先验生成长深度序列

全名：*DepthCrafter: Generating Consistent Long Depth Sequences for Open-world Videos*，2024 预印本，CVPR 2025。

把预训练图像到视频扩散模型改造成条件视频到深度模型，三阶段训练，融合真实与合成数据。输入 RGB 视频即可生成时序一致深度，不额外要求相机姿态或光流。长视频采用分段预测与拼接。

**值得看什么：** 大规模视频生成预训练中的时序先验，能否转成连续稳定的深度监督。

**Depth：** 输出深度序列，但无附加输入并不意味着保证绝对米制尺度；涉及机器人精确运动时仍应核对尺度。

来源：[作者项目页，含论文与代码入口](https://depthcrafter.github.io/)。

### 24. Depth Anything 3：深度与相机几何统一恢复

全名：*Depth Anything 3: Recovering the Visual Space from Any Views*，2025 技术报告，另有 ICLR 2026 学术版本。

任意数量图像，已知或未知相机位姿，预测空间一致几何，使用 depth-ray 表示；支持单图、多视图和视频重建。官方页面强调使用公开学术数据训练。

**与你已有论文的关系：** Qwen-RobotManip / Ego2Robot 用 DA3 估计场景深度，以决定机器人和真实物体的遮挡合成。

**数据来源区别：** 它是几何基础模型，不能简单归类为“只靠互联网人类操作视频训练机器人”。

来源：[作者项目页及代码入口](https://depth-anything-3.github.io/)。

### 25. MoGe-2：单 RGB 图像恢复具有米制尺度的点图

全名：*MoGe-2: Accurate Monocular Geometry with Metric Scale and Sharp Details*，2025。

从单张图像恢复 metric-scale 三维点图，同时处理相对几何、绝对尺度和细节。利用合成标签对真实数据做过滤和补全，改善混合来源几何监督。

**值得看什么：** 对机器人而言“前后关系正确”还不够，末端位移必须有可靠长度单位。MoGe-2 针对这个问题，但单帧米制预测也不自动保证整段视频一致。

来源：[论文](https://arxiv.org/abs/2507.02546)。

### 26. VGGT：从多视图一次预测相机、深度、点云与轨迹

全名：*VGGT: Visual Geometry Grounded Transformer*，CVPR 2025 最佳论文。

从一张、数张或数百张图像直接预测相机参数、深度图、三维点图和点轨迹，减少传统几何优化流程。

**值得看什么：** 怎样批量获得视频几何和相机信息，给动作恢复提供工具。

**需要核对：** 真实米制尺度、动态人手物体、遮挡与相机运动的区分，都需要具体流水线验证，不能仅凭能重建点云就认定得到可执行动作。

来源：[作者项目页及官方代码入口](https://vgg-t.github.io/)。

## 六、近期补充：怎样从海量视频中筛到有用示范

### 27. RoboTok：互联网规模的操作示范检索

全名：*RoboTok: An Internet-Scale Data Engine for Human Demonstration Retrieval and Dexterous Manipulation Learning*，2026-09-02 预印本。

给定一段目标人类操作视频，从网页视频中检索与机器人学习有关的示范。把三维手轨迹表达在估计的以行为者为中心的坐标系，学习潜在运动空间，以减少相机角度、场景外观和遮挡变化的影响，并支持持续索引。

**值得看什么：** 从“数据越多越好”进一步走到“怎样从更多数据里筛到动作相关、能帮助目标机器人任务的数据”。作者报告检索与下游策略改进，但不能仅据摘要认定它建立了多少小时的开放数据集。

来源：[论文](https://arxiv.org/abs/2609.03199)。

## 容易混淆、但阅读时很重要的边界

**Phantom 和 Masquerade 不是同一种输入。** Phantom 虽然标题是只用人类视频训练，但作者代码明确要求 RGB-D，且单只左手每帧可见；Masquerade 输入 EPIC-KITCHENS RGB，双手可能出现和遮挡，主要辅助监督是二维路标。要找普通 RGB 视频方案，优先读后者。来源：[作者 README](https://github.com/MarionLepert/phantom/blob/main/README.md)。

**已有 EgoMimic / EgoDex / EgoVerse 与互联网视频有不同数据条件。** 人类数据可以来自专门录制、带硬件跟踪的示范，也可以来自非结构化视频。筛论文时需要看实际输入是否带姿态/深度，不应只看标题中的 human video。你仓库中已经有 EgoVLA，值得和 VITRA 对照：先预测人类手腕手部动作，再 IK/重定向，少量机器人微调。来源：[EgoVLA 论文](https://arxiv.org/abs/2507.12440)。

**数据量与泛化的关系需要控制条件。** 更多异构数据可能产生负迁移，对齐与混合方式很重要。作为方法讨论补充，可读 *Rethinking Visual-Language-Action Model Scaling: Alignment, Mixture, and Regularization*（2026）。来源：[论文](https://arxiv.org/abs/2602.09722)。

## 按你的目标，最值得形成的三组对照

1. **显式三维与潜在动作：** VidBot / VITRA / Ego2Robot 对比 LAPA / JALA / CoMo。看重建误差、标注成本、运动语义和跨形态对齐。
2. **真实网络视频与生成视频：** Masquerade / Do as I Do 对比 DreamGen / Dream2Flow。看数据多样性与物理可执行性如何取舍。
3. **深度估计与动作恢复：** Video Depth Anything / DepthCrafter / DA3 提供几何；Track2Act / Dream2Flow 等再将视觉变化连接到控制。补深度是动作学习的一部分，不是整个机器人学习任务。
