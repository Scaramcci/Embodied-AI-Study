# F2：机器人运动学与人体到机器人重定向

这个目录承载 F2 的学习代码和证据。当前只展开第 1 课，不提前进入暂停的
SO-101 项目。

## 学习问题

人体肩、肘、腕的三维位置为什么不能直接作为机器人的关节角？怎样通过机器人的
运动学模型，把任务空间中的目标转换成合法的关节配置？

## 学习方式

面向已有计算机基础、但没有硬件经验的研究生：

- 重点掌握概念边界、系统接口、假设、失败模式和实验判断；
- 不把手算三角函数、默写推导或重复基础编码当作学习 gate；
- 公式用于说明变量关系，代码与测试交给计算机执行；
- 需要能够审查 AI 生成的实现：检查 frame、单位、joint order、limits、solver
  status 和误差，而不是只看程序是否运行；
- 每课沉淀概念笔记，并使用研究场景判断题检查理解。

## 学习顺序

| 阶段 | 内容 | 完成证据 | 状态 |
|---|---|---|---|
| F2.1 | joint/link/DoF/configuration；平面 2-link FK | 概念判断、FK 代码、单元测试 | 第一轮完成 |
| F2.2 | Jacobian；数值 IK；可达性 | 可达、边界、不可达测试 | 最低概念 Gate 通过 |
| F2.3 | 多解、奇异位形、joint limits | 多解图、限位统计 | 最低概念 Gate 通过 |
| F2.4 | 3–6 DoF 仿真机械臂 | IK 轨迹、误差表 | 未开始 |
| F2.5 | 肩—肘—腕归一化与重定向 | 末端/肘部约束可视化 | 概念学习中 |

依赖关系：`F2.1 -> F2.2 -> F2.3 -> F2.4 -> F2.5`。每个阶段通过后再展开
下一阶段。

## 当前运行方式

当前 `base` 是 Python 3.14 且没有 NumPy。已有 `Robot` 环境能够运行本课，暂时用：

```bash
conda run -n Robot python -m pytest \
  learning/f2_kinematics_retargeting/tests -v
```

这只是 F2 的临时运行入口，不代表路线要求的独立 `retarget` 环境已经建立或 F0
已经验收。

## F2 总 Gate

- 能从关节配置计算所有 link 端点和末端位置；
- IK 对可达、边界和不可达目标返回明确状态；
- 能解释同一目标的多个关节解以及初值的影响；
- 所有结果遵守 joint order、单位和 joint limits；
- 能说明人体和机器人在尺寸、拓扑、关节轴及 DoF 上的差异；
- 能把肩—肘—腕序列转换成末端和肘部约束并可视化。
