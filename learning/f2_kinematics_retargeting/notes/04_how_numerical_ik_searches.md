# 数值 IK 怎样寻找解

## 输入与输出

输入：机器人模型、目标末端 pose、初始关节配置和约束。输出：候选关节配置以及
求解状态。IK 不直接驱动硬件。

## 搜索循环

复杂机器人通常没有方便的解析公式。数值 IK 从一个初始配置开始反复执行：

```text
1. 猜一个 q
2. 用 FK(q) 计算当前末端 pose
3. 比较当前末端与目标，得到 task error
4. 根据局部运动关系修改 q
5. 重复，直到误差足够小或满足停止条件
```

Jacobian 在第 4 步提供“当前姿态下，哪个关节稍微转动会让末端朝哪个方向移动”
的局部信息。它是搜索方向工具，不是目标，也不是硬件命令。

## 三种终止结果

- 成功：误差低于阈值，并满足求解器内的约束；
- 失败：达到迭代上限、目标不可达、约束冲突或数值状态不良；
- 可疑：求解器报告结束但误差仍大，或只满足了部分目标。因此必须读取 status、
  error，并做 FK 回代。

## 初值为什么重要

数值 IK 是从初值附近开始搜索。同一个目标存在多个解时，不同初值可能到达不同
解分支；不好的初值也可能使求解变慢或失败。处理轨迹时常用上一帧解作为下一帧
初值，以保持分支和动作连续。

## 与机器学习训练的类比

```text
机器学习：参数 -> forward -> loss -> gradient -> 更新参数
数值 IK：q    -> FK      -> pose error -> Jacobian/优化 -> 更新 q
```

这只是优化结构上的类比。IK 通常针对一个目标在线求解关节变量，并不意味着训练
了一个可泛化的神经网络。
