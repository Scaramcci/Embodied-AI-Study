# F2 收尾：从人体观测到可执行机器人轨迹

## 本课目标

不要求手算 IK 或推导 Jacobian。学完后应能在阅读论文时识别：输入是什么观测，
作者保留了什么动作意图，使用了哪些约束，以及输出为什么可以或不可以执行。

## 一条必须记住的主线

```text
人体关键点是观测，不是机器人命令
    ↓  质量检查、frame 对齐、去除整体平移、尺寸映射
机器人任务目标（腕部、肘部、姿态、arm plane）
    ↓  受限 IK 或轨迹优化
候选关节轨迹 q[1:T]
    ↓  FK、limits、连续性、速度、碰撞和 solver status 检查
可执行轨迹或显式失败
```

## 1. 重定向保留的是任务意图

人和机器人的骨段长度、关节轴、自由度和拓扑并不相同，因此不存在通用的
`人体坐标 -> robot joint angle` 直接复制。系统通常选择保留某些任务特征：

- 腕部位置：手到哪里；
- 腕部姿态：手如何朝向；
- 肘部位置或 arm plane：手臂如何弯曲；
- 时间连续性：动作不要在相邻帧之间跳解。

所以，“重定向得好”不等于每个人体点都和机器人点完全重合，而是主要任务意图
在机器人的物理约束内尽量被保留。

## 2. 预处理各自解决不同问题

| 步骤 | 解决的问题 | 不能解决的问题 |
|---|---|---|
| 质量检查 | 遮挡、低置信度、丢帧、突变 | 坐标系不同 |
| frame 对齐 | camera frame 到 robot base frame | 人机尺寸差异 |
| root centering | 去掉人在画面中整体站位的影响 | 手臂长度不同 |
| scale normalization | 把人体动作幅度映射到机器人 workspace | 关节轴、DoF 和拓扑不同 |
| 受限求解 | 在任务目标与机器人约束之间找折中 | 输入本身缺失的意图 |

一个常见错误是把所有问题归结为“加一个缩放系数”。缩放只改变尺寸，不会自动修复
frame、拓扑、关节轴或可达性问题。

## 3. 硬约束、软约束与优先级

- 硬约束：不能违反，例如 joint limits、某些碰撞与安全边界。
- 软约束：尽量满足，用 loss 权重表示取舍，例如腕部误差、肘部误差和平滑项。
- 优先级：冲突时决定先牺牲什么。一般不能为了完全复制人体肘部而突破机器人限位。

论文中的 loss 本质上是作者对“什么才算动作像”的可计算定义。阅读时要问：

1. 哪些项是主任务，哪些只是 regularization？
2. 权重改变后，会牺牲位置、姿态、形态还是平滑性？
3. 安全条件是硬边界，还是只被写成可以违反的 penalty？

## 4. 逐帧 IK 与轨迹优化

| 方法 | 优点 | 主要风险 |
|---|---|---|
| 逐帧 IK | 快、易初始化、适合在线处理 | 相邻帧可能落入不同解分支，导致关节跳变 |
| 轨迹优化 | 可同时约束速度、加速度和整段平滑性 | 计算更贵，仍受初值、局部最优和权重影响 |

实用组合是：先用上一帧的解 warm start 逐帧 IK，再对整段轨迹做平滑或联合优化。

## 5. “求解成功”不等于“可执行”

最终至少要检查：

- `FK(q)` 的任务误差，不只信 solver 的 `success`；
- joint order、单位和 joint limits；
- 相邻帧关节跳变、速度和加速度；
- 碰撞、自碰撞与环境安全边界；
- 不可达帧、低置信度帧和求解失败的显式状态。

平均误差小也不够，因为少数失败帧可能被平均值隐藏，而这些帧恰好可能在抓取或
接触时刻造成任务失败。

## F2 最后概念 Gate

### 场景 1

相机中的手腕坐标数值已经小于机器人最大臂展，能否因此判定目标可达？
说明至少两个还必须检查的条件。

### 场景 2

两条轨迹的腕部平均误差相同。A 的肘部更像人，但在第 80 帧超过 joint limit；
B 的肘部误差略大，但全程合法平滑。哪条更可执行，为什么？

### 场景 3

逐帧 IK 每帧的 `solver_success=True`，但关节角在相邻帧大幅跳变。这说明哪一类
约束或验证缺失？可以怎样修正？

## 通过标准

能用自己的话回答三个场景，并明确区分“观测”、“任务目标”、“关节轨迹”和
“可执行轨迹”，即可进入 F3。不要求手算、推导或从头实现求解器。
