# IK 约束、奇异位形与冗余

## 最小结论

IK 的任务不是随便找到一组能到达目标的关节角，而是在候选解中寻找满足约束、
适合连续执行的配置。末端误差只是一个指标。

## Joint limits

每个关节都有合法范围：

```text
q_min <= q <= q_max
```

来源包括机械结构、电缆、防碰撞设计和控制器限制。位置在数学上可达，不代表存在
满足 limits 的解。

不要把 unconstrained IK 的输出简单裁剪到 limits：逐元素裁剪后，末端通常不再
到达目标。更合理的方式是把 bounds 放进求解过程，再对输出做独立检查。

除了“是否越界”，还要关注 limit margin。两个解都合法时，远离边界的解通常保留
更多后续运动空间，对噪声和目标变化也更稳健。

## 奇异位形

奇异位形是机器人在某个配置下丢失部分瞬时运动能力。此时 Jacobian 丢秩或病态：

- 某个末端方向无法由关节小运动产生；
- 很小的末端目标变化可能要求很大的关节变化；
- Jacobian 逆/伪逆会放大噪声；
- IK 可能变慢、跳变或失败。

目标处于 workspace 边界时常接近奇异，但“奇异”描述的是配置与局部运动能力，
不能简单等同于“目标不可达”。

常见处理：避免奇异区域；选择 manipulability 更好的候选解；damped least
squares；限制关节速度；对轨迹加入连续性和平滑约束。

## 冗余

当机器人可调 DoF 多于当前任务约束时，称为冗余。例如 7-DoF 机械臂只要求三维
末端位置，会有大量配置满足同一目标。

冗余不是错误，而是选择空间。多出来的自由度可以用于次级任务：

- 远离 joint limits；
- 避免碰撞；
- 保持肘部朝向或模仿人体 arm plane；
- 提高 manipulability、远离奇异；
- 靠近上一帧配置，保持轨迹连续；
- 保持相机视野或工具姿态。

## 候选解的典型选择目标

概念上可以写成：

```text
总目标 = 末端跟踪误差
       + 关节连续性代价
       + joint-limit 代价
       + 奇异性代价
       + 碰撞代价
       + 人体姿态/arm-plane 代价
```

各项是否作为硬约束或软代价，取决于安全性和任务设计。安全限位通常不能仅靠软
惩罚保证。

## 三个容易混淆的概念

- **不可达**：不存在满足当前目标和约束的配置；
- **奇异**：当前配置的局部运动映射退化；
- **冗余**：满足任务的配置不唯一，还有自由度可优化次级目标。

它们可以同时出现，但含义不同。

## 审查清单

看到 IK 结果时检查：

1. bounds 是否在求解过程中生效；
2. 输出距离 limits 还有多少裕量；
3. 是否报告任务误差和 solver status；
4. 相邻帧是否发生解分支跳变；
5. 是否接近奇异配置；
6. 冗余自由度由什么次级目标决定；
7. 碰撞是否由独立模块检查。
