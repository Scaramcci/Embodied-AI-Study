# 学习规划总览

## 当前决定

- 公共基础是两条项目线的前置，但只补当前任务用得上的内容。
- 老师论文是当前主线。目标是读懂方法、理清复现条件，并做一个可运行的小型实验。
- SO-101 机械臂项目暂停。本仓库只保留规划和已验证记录，暂不采购、搭建实机或训练 ACT。

## 使用规则

1. 开始学习时，先看当前路线的 `README.md`、`ROADMAP.md` 和状态记录。
2. 任务完成以笔记、代码输出、图表或可重复命令为证据。“看完了”不算完成。
3. 论文中遇到基础缺口时，回到公共基础定向补齐，不扩展成完整课程。
4. 机械臂子项目在明确恢复前，不占用当前学习时间。
